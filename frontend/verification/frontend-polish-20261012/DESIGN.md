# 设计参考锁定与决策（实施前冻结，2026-10-12）

## 简报

为跨境电商运营人员优化“航标”桌面优先证据工作台。目标是快速识别店铺/对象、状态、证据与限制，以及可执行的下一步。路径是既有设计体系直接实施，不创建新品牌或虚构数据。

## 研究来源

- 主来源：本次受控浏览器的 before 截图，来自真实入口 `src/main.tsx → workbench/Workbench.tsx`、当前 CSS 与主题配置。既有深海军蓝导航、白色数据面板与克制青绿色操作保留。
- 辅助来源：已读 refero-design bundled `typography.md`（中性工作界面、单字体、字号层级、数字对齐）、`color.md`（低彩度数据界面和颜色语义）、`craft-details.md`（焦点、复合控件、触屏表单）、`anti-ai-slop.md`（去装饰化、不虚构）、`visual-workflow.md`（源参考锁定和浏览器视觉 QA）。未访问 Refero 在线库；没有在线研究的声明。
- 本次 before 图发现：调查介绍横跨整屏且很长；中文标题衬线与正文差距过大；多个表单靠固定宽度 Space 排布；报告小屏没有局部横向滚动，表格细列产生极高行；列表总数和服务端页码不清楚；青绿色主题配置与 CSS 分别有两个值。

## 参考锁

保持：海军蓝导航、白色数据面板、授权店铺上下文、青绿色主要操作、数据工作台的紧凑密度。借用：craft 的键盘焦点/响应式表单；typography 的中性字阶和数字对齐。不引入营销插画、KPI、泛用卡片网格、渐变主画布或展示性动效。真实状态与证据限制优先。

## Decision ledger

| 决定 | 来源/角色 | 原因 |
|---|---|---|
| 页标题改系统无衬线28px；正文14px | typography 的工作界面中性层级 | 工作台扫描优先，避免介绍与主体争抢视觉层级 |
| 保留导航，统一主题操作色 | 既有航标；color 的严格颜色角色 | 当前配置的亮青色与 CSS 不一致；绿色不能用来暗示核查成功 |
| 调查模式与对象双列，内部草稿选项与操作分行 | before 表单 + craft | 固定宽度 Space 在手机难以读；主操作可键盘到达 |
| 简短介绍，外部操作限制与费用授权提示保持可见 | 用户简报 + 既有边界 | 减少重复文字，不移走关键限制 |
| 语义取证与历史报告优先，原文检索保留为独立区域 | 用户目标“当前任务/下一步” | 用户进入报告页能先看到生成任务和历史报告 |
| 检索基础字段优先；语言/主题/极性/SKU 为展开筛选 | craft 表单分组 | 明确主查询动作，降低首屏拥挤且保留筛选能力 |
| 报告/任务表格 x 轴局部滚动 + 总数 + 正确分页 | before 实际细列 + 用户要求 | 保留可读列宽，历史51条可达，不拉取全部 |
| 可见错误与只读重试，未知 match_kind 显示待确认 | 产品真实证据边界 | 不把失败渲染为空，不把未知渲染成已判定 |
| focus-visible 与 :focus-within、数字tabular | craft / typography | 支持键盘、复合选择器以及时间和数量扫描 |

## QA 计划

对照相同受控fixture与1440/768/390截图核对导航、文字层级、授权提示、失败和未知状态、表单/表格溢出。保存请求日志、console、pageerror；当前证据只代表受控浏览器，不代表生产接入或模型质量。

## QA 后的语义标签校正

小字号状态标签只调整文字与浅色表面：警示/部分完成使用 #80500b / #fff4dc；相关命中使用 #075f5d / #e6f5f3；失败使用 #a52b37 / #fff0f0。来源为 color 的语义用色与可读性规则、用户“不能把未完成美化为成功”的约束。未改变状态含义。适配本地 Ant Design 6 默认 filled 标签（已核查该依赖的 useColor/presetCmp 实现），同时保留 outlined 支持，不改 solid/disabled 语义。浏览器保存 computed colors 与 contrast-*.json，部分完成6.26:1、相关命中6.68:1，超过4.5:1。占位与说明文字使用既有 muted/secondary tokens，不新增品牌颜色。
