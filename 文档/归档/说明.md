## 已知冲突（归档文档 vs V2）

保留此清单是为了让读到旧文档的人不被误导。

### 1. L1 / L2 定性相反

- 阶段2 冻结「Task Router + L0 + L1 + **L2 Investigation Agent**」。
- 阶段3 的评测包含 Next-step / Re-plan / Stop 等 **L2 指标**。
- 阶段4 整份文档围绕 **L2 Agent** 设计。
- **V2 第 5 节**：交付采用 L0 查询和 L1 场景工作流，受限自然语言追问纳入同一次交付；动态多 Agent 调查明确不在范围内。

### 2. 架构图为早期多 Agent 设想

- 图中为多 Agent 协作（`ReviewSearchAgent` / `TrendAnalysisAgent` / `CompetitorInsightAgent` / `Insight Orchestrator`），V2 明确「不堆多 Agent」。
- 图含竞品分析（`CompetitorInsightAgent`、竞品差异分析），V2 明确不交付竞品分析，不作后续版本承诺。
- 图中组件名 `CitationGuard`，实现与 V2 中为 **Evidence Guard**。
- 图中底座含 Reranker / Qdrant / Langfuse / Worker；V2 首发 Keyword，Qdrant 与 Reranker 为实验后端，实现使用自建 tracing 与 `ThreadPoolExecutor`。
- 图**完全未包含** V2 的完整业务主干：异常检测引擎、退款/售后/库存/价格证据源、候选原因排序、异常队列、人工确认分派。

### 3. 时间窗口口径

历史实现主要使用月度数据。V2 第 8、9 节明确日常经营、反馈和成熟销售队列采用不同窗口；旧月表只用于历史复盘，不能伪造日数据或用于每日监控验收。
