### Gate 1：S1—S3 P0 技术门槛

1. **S1 权限与任务横向门槛**
   - 执行现有权限、审计、并发、撤权、固定图恢复专项。
   - 追加真实供应商调用前的逐工具权限矩阵：读取、导出、调查恢复、内部草稿写入分别验证授权、撤权、跨店铺和过期代数。
   - 退出条件：每个 API/任务入口都有匿名、跨工作区、撤权后、旧版本/旧代数四类结果；成功回执与审计同事务。

2. **S2 真实来源与生命周期**
   - 用九类脱敏报表逐类执行上传→预览→发布→修订→重算→下载追溯。
   - 每类至少执行：非法编码、超宽字段、缺报、迟到、重复发布、最后分块撤权、文件消失/权限错误、评论删除恢复、退货申请→收到→取消。
   - 对“撤销发布”先做业务决策：若只是纠错，记录为修订/删除命令；若确需整批回退，再单独定义权限、影响范围、审计和不可误删保护。
   - 退出条件：每个来源有字段映射、覆盖日期、原文件、原始行和修订结果证据；失败不会生成成功发布回执。

3. **S3 指标、事件与调度**
   - 用真实财务/评分样本核对成熟退货退款、跨月发生量、部分退款、全冲正、未知币种、页面星级与采集均分。
   - 执行扫描→事件生成→领取/分派→动作→观察→关闭→新导入复发；另测跨问题族合并/拆分和暂缓/升级。
   - 执行调度停机、重启、跨工作区并发和计划重新启用；核对站点日期、DST 和逐日回执。
   - 退出条件：每个已知答案有输入、期望值、实际值和依据；事件不重复、版本冲突可见、关闭后新证据能正确复发。

### Gate 2：S4 真实语义与报告

1. 确认供应商、模型、区域、预算和脱敏传输边界；密钥只通过环境变量注入。
2. 用固定标注集执行五场景标准取证、EvidenceFact 统计契约、候选解释、反证、缺口和安全分流。
3. 单独执行 Recall@10、覆盖率、主题趋势、Fisher/BH、真实超时重试、恶意原文/否定/假设/伪造授权样本。
4. 验证语义运行中断后按评论回执恢复，不重复 claim，不切换来源版本；导出 HTML/JSON/CSV 并复核权限、引用和脱敏。
5. 退出条件：模型失败时仍有规则报告和明确 deferred/partial 状态；真实标注集达到需求中约定的质量门槛；所有报告引用可回到当前快照和原文。

### Gate 3：S5 业务验收（代码已完成）

1. 选真实 Amazon 脱敏/授权样本，完成任务创建、修订、正式指派、执行、观察、复查、关闭和复发。
2. 覆盖不同站点时区、品类观察期、成熟订单和缺失指标；记录基线、当前值、窗口、快照和结论。
3. 对价格、库存、Listing 提案执行人工批准、内容哈希复核、唯一交接编号和人工执行回执；确认系统没有外部写接口。
4. 验证通知链路、权限过滤、逾期幂等和真实运营人员可读性。
5. 退出条件：业务负责人签收动作字段、复查结论、人工交接和通知；签收前 S5 保持“代码已实现/业务待验收”。

### Gate 4：S6 自主调查

1. 补 L0/L1/L2 路由：明确 ASIN、模糊 ASIN、SKU/别名、多店铺候选、澄清后继续。
2. 将 `choose` 从关键词固定分支升级为可审计的模型决策；准备成对样本，要求不同中间证据选择不同工具，并能用反证推翻候选解释。
3. 建立单次调查账本：步骤数、模型尝试数、token、费用、累计时间、重复查询、停止原因；恢复时不得重置额度。
4. 做运行中取消、恢复跳过定位、逐工具撤权、恶意原文、伪造授权、安全正例并存和写入后 checkpoint 故障。
5. 补调查浏览器用例：历史、进度、澄清、部分结果、恢复、无权状态、内部草稿回执。
6. 退出条件：每次工具调用都有输入快照、权限判定、预算扣减、证据引用和回执；模型不可直接执行外部经营变更。

### Gate 5：S7 发布验收

1. **镜像和部署：** 构建生产镜像，启动全 Compose，验证迁移门控、健康/就绪、TLS/Cookie、密钥、日志轮转和非 root 运行。
2. **故障恢复：** 分别停止数据库、Redis、worker、beat；覆盖副作用写入后崩溃、重复投递、模型决策、内部写入和多维预算恢复。
3. **备份与保留：** 做数据库+原文件+索引+密钥引用的联合备份；在隔离环境恢复并核对全对象、引用和审计；记录 RPO/RTO。实现 180 日可配置保留、来源授权更短优先、派生索引/审计清理和删除引用占位。
4. **性能：** 在目标机器用 1000 ASIN、10 万记录、10 人并发，记录查询 P95、扫描总时长、索引构建、队列积压、错误率和资源峰值。
5. **全流程：** 导入→指标→事件→语义报告→调查→动作→观察→关闭→复发，逐项回放 AC-01—AC-26。
6. **影子运行：** 至少 3 周、2 名运营、10 个真实子 ASIN、30 个已核查事件；记录主动调查时间、明确动作比例、一般事件无效告警率和安全告警。
7. **退出条件：** 生产、恢复、容量、保留期、全 AC、影子运行和用户签收全部有证据；任一 P0 未关闭不得发布。
