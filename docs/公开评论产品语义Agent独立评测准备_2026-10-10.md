## 实际入口与映射

使用现有产品链路：`build_semantic_service → SemanticExtractionService.extract → PromptBuilder → DeepSeekResponsesGateway → SemanticParser → SemanticGuard`。配置与`insight.semantic.service.ProviderAdapter`的产品prompt `semantic-prompt-v1.2`和`taxonomy-v1.1`一致，常量runtime身份一致。仅运行评测所需的内存语义链路，不写业务数据库。已有产品Adapter最多2次尝试；本评测显式降为1次，SDK重试为0，超时30秒，网关外的透明客户端增加输出上限/strict及持久调用收据，不改提示词、taxonomy、parser或guard。

没有编写读取银标签生成答案的分类器，也没有扩充产品taxonomy。充电器体系与7个宽主题不能一一对应；以下映射仅在预测封存后评分时应用，固定版本`product-to-public-broad-v1`：

| 产品类别 | 公开宽主题 |
|---|---|
| function_performance | function |
| reliability_durability | durability |
| compatibility_fit | compatibility |
| usability_installation | function |
| convenience_value / price_value | value |
| convenience_value / 其他子主题 | function |
| safety_risk、product_quality | other |
| other_unknown | uncertain，不作为可比标签 |

原产品体系没有appearance/service出口，保持这两个主题在7类macro-F1的分母中，不人为补答案。product_quality并非银标签durability的同义词，映射到other会产生范围差异。只聚合accepted claims；无accepted为abstain，纯neutral为neutral_unmapped，正负同时出现或mixed为mixed，只有正/负加neutral则保留有方向的polarity。保留所有原claims、证据、guard状态和拒绝理由；不重写quote或修复产品预测的证据。

因此本评测是**产品语义链路跨领域宽主题一致性比较**，不是完整调查Agent验收，也不能将其数字称真实准确率。

## 标签隔离、冻结与证据

准备程序只读冻结文本/manifest并验证原SHA；预测输入仅包含review_id/text，不含split、label或其他来源元数据。产品代码、taxonomy、三个脚本及输入被复制到唯一run并计算哈希。独立worker从快照导入产品模块；Python audit拒绝仓库内除该run及Python虚拟环境外的文件读取，边界构造测试已验证。不存在从标注目录读收据的路径；该隔离针对本程序文件访问，不宣称是防恶意本地进程的操作系统沙箱。

付费前逐项重验快照hash；必须有单独`approval.json`，精确绑定计划hash、新总额/单次上限及传输确认。调用前持久写入预留收据；失败不重试，含未知收费状态。已出现receipts目录的run拒绝再次执行。进程被中断时留原收据，不自动续跑，须另行审计。

预测全部完成后先写raw-predictions、execution-report、prediction-seal；execution-report绑定每份请求/返回收据hash、模型请求身份、返回身份/response ID及usage原响应，原始响应未删。评分命令须通过预测封存及收据hash核验，才读取银标签和语义问题清单。模型别名、返回model字段和usage是供应商报告，不是权重或账单的独立证明。

本阶段没有按validation/holdout答案诊断或调参，也没有重跑标注。development/validation/holdout沿原split；原260可用、40未解决及24语义问题保持只读。

## 评分契约

每个split分别输出：总输入、标签覆盖/未解决、预测labeled/abstain/uncertain/neutral_unmapped/failed、全输入预测覆盖、可用标签比较覆盖、polarity三类macro-F1及topic七类macro-F1。

同时输出仅比较成功预测的条件一致性和将缺失预测计作错误的覆盖惩罚一致性，避免只看成功子集。固定所有类别参与macro平均，无支持类别按0处理，需结合支持量理解。40未解决保留300全输入覆盖分母，不提供虚构gold；24语义分歧独立分split统计且仍纳入主结果，不静默剔除。所有指标仅与AI银标签的一致性，非独立人工准确率、非新盲测。
