## 成本与并发边界

应用有单调查 `max_steps` 与持久化调用账本；启用外部模型时还校验配置的单调用、单 run 和评测整轮费用上限。provider 默认由配置显式启用，区域、传输授权及费用配置缺失时外部 planner 会拒绝运行。以上不是工作空间级总额控制。

目前没有跨用户、跨门店的工作空间日/月成本累计上限，也没有聚合并发调查上限。相同用户、门店和调查范围的重复活动 run 会冲突，但不同 run 可并行排队；Celery 的 `--concurrency=2` 只是单 worker 进程设置，不限制多个 worker 合计并发。本轮免费验证显式关闭 provider，没有发起付费调用。

因此，生产或扩大付费运行前仍需定义并实现工作空间级日/月预算与并发上限，并为缺少配置的环境保持付费调度关闭。本文不填造金额、不把单 run cap 当成 workspace cap，也不把历史预留额解释为供应商账单。
