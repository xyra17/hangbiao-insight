# S5 真实脱敏样本验收

本验收使用仓库内冻结的评论黄金集作为**脱敏真实业务语料**，不把它描述为 Amazon 在线实时数据。样本位于：

- `dataset/data/03_黄金评论集/黄金评论主表_v1_0.csv`：360 条已冻结评论；
- `dataset/data/03_黄金评论集/黄金评论标签表_v1_0.csv`：657 条已冻结语义标签；
- 覆盖 3 个脱敏商品、英文标题与正文、背景窗口和重点窗口、正负面主题及否定语境。

验收入口是 `backend/tests_v2/test_s5_real_sample_acceptance.py`。它校验样本版本标记、评论与标签可通过 `review_id` 关联、证据跨度能回指标题或正文、商品覆盖以及明显个人信息不进入样本。

这组样本用于验证 S5 的证据引用和复查页面输入质量；`dataset/data/02_构造经营指标/经营指标日宽表_v1.csv` 明确标记为 `synthetic`，只用于算法边界测试，不作为真实经营效果验收。真实账户的订单、退款、退货和复查效果仍需业务方提供合法脱敏报表后再验收，不能由这组评论样本替代。

当前测试结果：2/2 通过（样本完整性、证据跨度回指和脱敏检查）。
