- `EVIDENCE_RELEVANCE_PROVIDER=deepseek`，`INSIGHT_ENABLED_MODEL_PROVIDERS`须含deepseek；授权引用和区域不能为空。
- 候选默认20/硬上限30；请求默认12000/上限24000 bytes；输出默认3000/上限6000 tokens；单次默认成本上限0.02（使用供应商报价同一币种）；timeout默认10秒/上限30秒，无重试。

- 超时、429、未知判断、缺usage、非法输出或候选截断显示未完成；不能视作确定无答案。调用失败时费用可能未知，ledger的0不能解释为供应商实际免费。

```sh
# 环境和批准配置注入后运行真实生产边界；报告后缀必须唯一。
cd backend
INVESTIGATION_EVAL_PROVIDER=deepseek INVESTIGATION_EVAL_REPORT_SUFFIX=approved_relevance_run uv run --env-file ../.env.local pytest -c pytest-v2.ini tests_v2/test_s4_s6_runtime_acceptance.py -m 'not capacity' -q

# 对新runtime生成新模板，再由独立人员裁决；下面文件路径应换成同一次运行。
python3 dataset/adapt_investigation_outputs.py --runtime-report RUNTIME.json --write-template NEW_ADJUDICATIONS.csv --output ADAPTED_PENDING.json
python3 dataset/adapt_investigation_outputs.py --runtime-report RUNTIME.json --adjudications NEW_ADJUDICATIONS.csv --output ADAPTED.json

python3 dataset/quality_gate.py --retrieval RETRIEVAL.json --paired RUNTIME.json --adapted ADAPTED.json --scoring SCORE.json --bundle-output BUNDLE.json --output GATE.json
```
