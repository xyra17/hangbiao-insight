# 字段与口径说明

| 字段 / 文件 | 说明 |
| --- | --- |
| `shop_a`、`shop_b` | 两个相互独立的测试店铺目录；各覆盖 500 个唯一测试 ASIN。 |
| `sales_traffic_v1.csv` | 每 ASIN 每日一行。`ordered_units`/`order_count` 对应本包订单行，`sessions` 为 ASIN 粒度，金额使用 USD 合成金额。共 100,000 行。 |
| `orders_v1.csv` | `record_id` 为订单行键，`order_id` 为订单键，`shipped_date`/`shipped_at` 定义发货队列日期。偏斜 ASIN 每日 40 行，其余每个 ASIN 每日 1 行。合计 178,000 行。 |
| `support_cases_v1.csv` | 每 ASIN 一条客服记录，`order_line_id` 关联订单行；正文恰为至少 4,096 字符并以 `[SYNTHETIC CAPACITY SUPPORT CASE]` 开头。共 1,000 行。 |
| `sales_traffic_revision_v2.csv` | 与同一主销售来源、同一最终业务日记录键相同的修订行，用于校验版本覆盖；不是额外的第二主来源。共 1,000 行。 |
| `generation_version` | 必须是 `s7-capacity-v1.0`；sidecar 的 `package_version` 与记录标记必须一致。 |
| `provenance_class`、`is_real`、`is_derived`、`is_synthetic` | 数据血缘标记；所有输入行均为合成。销售日行和修订行为由测试场景派生的合成事实。 |

容量文件中 Sessions 是 ASIN 日级数值；不要将同一 ASIN 的 SKU Sessions 相加。本包支持数据库导入、修订生效、长文本索引和关联检索的容量测量，但本机资源数据不能替代目标环境的 CPU、内存、队列和并发验收。
