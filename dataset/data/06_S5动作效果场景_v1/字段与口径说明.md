# 字段与口径说明

| 文件 / 字段 | 说明 |
| --- | --- |
| `scenario_id` | 稳定场景键；值对应生成器情景。 |
| `asin` | 与经营闭环包中对应 ASIN 一致的合成测试标识。 |
| `metric` | 用于复查的指标键，例如 `ordered_units`。 |
| `effective_date` | 预期实际生效的站点日；窗口按站点日解释。 |
| `baseline`、`observation` | 28 天基线与 7 天观察窗口的每日均值，最多保留 6 位小数。退款/退货率仍按成熟队列比率比较。 |
| `baseline_total`、`observation_total` | 对应窗口的原始指标总量；缺报场景留空。 |
| `baseline_days`、`observation_days` | 每个汇总窗口实际天数；完整销量场景分别为 28 和 7 天。 |
| `baseline_start`、`baseline_end`、`observation_start`、`observation_end` | 每个窗口的站点日边界；动作生效间隔日不并入任一窗口。 |
| `unit` | 销量为 `units/day`。退款/退货率应按成熟发货队列比较，不按销售日总量替代。 |
| `expected_outcome` | `improved`、`no_material_change`、`worsened`、`not_reviewable` 或 `reopened_on_new_evidence` 的预期行为。不是因果判断。 |
| `task_status`、`review_status` | 动作和复查 API 的目标状态。窗口不足或覆盖不完整时预期拒绝完成复查。 |
| `required_maturity` | 完成复查前须满足的观察窗口/发货队列成熟条件。 |
| `missing_data`、`expected_stop_reason` | 显式缺报标记与预期停止原因；未知数据不能按零处理。 |
| `asin_role` | 运行次序或场景约束提示。 |

`task_templates.json` 的 `shop`、`assigned_to`、`event` 与 `snapshot` 是占位符；模板不包含真实 UUID、用户或授权。
