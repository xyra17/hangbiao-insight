# 字段与口径说明

## 通用字段

| 字段 | 说明 |
| --- | --- |
| `child_asin` | 合成隔离测试标识，不是 Amazon 商品目录声明。 |
| `seller_sku`、`fulfillment` | SKU 和履约维度；Sessions 只在 ASIN 日粒度提供，不能累加 SKU Sessions。 |
| `business_date` | 按 `America/Los_Angeles` 解释的站点业务日。 |
| `provenance_class`、`is_real`、`is_derived`、`is_synthetic` | 来源标记；所有记录均为合成，部分日汇总由订单行派生。 |
| `source_reference`、`source_row_id`、`generation_version`、`scenario_id` | 生成来源、稳定行标识、生成版本和情景标识。导入时这些列列入忽略列，不写入业务事实字段。 |

## 文件字段

| 文件 / 类型 | 主要字段和口径 |
| --- | --- |
| `sales_traffic_daily_v1.csv` / `sales_traffic` | 每 ASIN 每日一行。`ordered_units` 为订单行 `quantity` 合计，`order_count` 为去重订单号，`sales_amount` 为订单行数量乘合成单价；`sessions` 是 ASIN 级独立值。 |
| `orders_v1.csv` / `orders` | `record_id` 唯一订单行，`order_id` 可跨多行，`quantity`/`shipped_quantity` 为行数量，`shipped_date`/`shipped_at` 提供发货队列边界，`is_exchange` 明确换货排除条件。 |
| `refunds_v1.csv` / `refunds` | `order_line_id` 关联订单行；`transaction_chain_id` 与 `currency` 一起界定正向退款和冲正链；金额是带符号金额。 |
| `returns_v1.csv` / `returns` | 事件契约统一为仓库收到；同时给出 `requested_*` 和 `received_*`，避免把申请和收到混为同一事件。 |
| `inventory_daily_v1.csv` / `inventory` | `available`、`reserved`、`inbound`、`unsellable`、`total` 为合成日库存；`listing_status` 是独立状态字段。 |
| `ratings_daily_v1.csv` / `ratings` | `rating` 为合成平均评分，`rating_count` 为快照样本量。 |
| `operations_v1.csv` / `operations` | `event_type`、`description`、`ends_on`、`price`、`currency`、`mechanism` 描述合成促销/价格背景，不代表真实卖家记录。 |
| `reviews_v1.csv` / `reviews` | `record_id` 是 SYN 命名空间；`text` 明确标注 `[SYNTHETIC REVIEW]`，不得用作黄金评论。 |
| `support_cases_v1.csv` / `support` | `order_line_id` 关联订单行；`text` 明确标注 `[SYNTHETIC SUPPORT CASE]`，不源自评论主题或真实客服工单。 |

缺报与未来复发夹具各有独立 sidecar、日期范围和 `declared_asins`。不能将缺报空档填零，也不能把未来日期夹具并入截至 2026-09-30 的主批次。
