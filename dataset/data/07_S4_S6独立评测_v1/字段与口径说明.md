# 字段与口径说明

| 文件 | 字段 / 口径 |
| --- | --- |
| `paired_investigation_scenarios.csv` | `pair_id` 将两个证据变体绑为一个切分单元；`query` 在一对内固定；`expected_route`、`expected_behavior`、`expected_answer_outline` 与 `forbidden_conclusion` 是预期决策契约；`expected_stop_condition`、`expected_tool_names` 指明拒答/工具边界；`review_split` 与 `split` 取 `development`、`validation`、`test` 之一；`review_id` 使用合成 SYN 命名空间。 |
| `retrieval_queries.csv` | `query_id` 唯一查询键；`language` 为 `en` 或 `zh`；`topic` 为测试主题；`answerable` 表示包内是否存在相关候选；`expected_stop_condition` 描述应检索或停止；`split`/`review_split` 是 query 级切分。 |
| `retrieval_documents.csv` | `doc_id` 唯一候选键；`kind`、`asin`、`business_date`、`title`、`text`、`language`、`topic` 是检索字段；`review_id` 是 SYN 标识而非真实 Review ID；`source_split`、`split` 必须与其查询一致。 |
| `retrieval_qrels.csv` | `query_id` 与 `doc_id` 定义一条人工不可解释为真实标注的机器合成相关性判断；`relevance=1` 表示本合成夹具指定为相关；`split` 与关联查询和文档相同。不可回答查询没有正向 qrels。 |
| `rare_topic_extension_candidates.csv` | `candidate_id` 唯一候选键；`label=candidate_only`；`golden_status=synthetic_unreviewed`；该表不是新的黄金集，不能混入测试集评分。 |

切分采用固定轮转方案，不按单行拆开成对变体。若更改查询、文档或 qrels，应同步更新 manifest 数量及生成校验报告。
